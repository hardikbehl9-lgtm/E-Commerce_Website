# E-Commerce_Website

# 👟 SNEAKERBOX - Premium E-Commerce Storefront

A high-end, responsive glassmorphism web application built with React, Vite, and Client-Side Routing. Features real-time search, brand filtering, interactive wishlists, light/dark mode transitions, and an automated assistant chatbot overlay.

## ✨ Key System Features
* **Premium Glassmorphism UI:** Backdrop filters and clean hover transformations.
* **Smart Catalog:** Real-time state updates for product filtering.
* **Interactive AI Chatbot:** Seamless pure-frontend support panel interaction.
* **Full Responsive View:** Perfect spec rendering across mobile and desktop.
